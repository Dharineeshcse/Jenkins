# Jenkins DevOps Learning

This repository is created for learning Jenkins from beginner to advanced.

Topics covered:

- Freestyle Jobs
- Pipeline Jobs
- Git Integration
- Build Triggers
- Parameters
- Environment Variables
- Unit Testing
- Docker
- Kubernetes
- Artifact Archiving
- JUnit Reports
- GitHub Webhooks

Project Structure

```
app/            Python Application
tests/          Unit Tests
scripts/        Build Scripts
artifacts/      Generated Files
reports/        Test Reports
kubernetes/     Kubernetes Manifests
Dockerfile      Docker Image
Jenkinsfile     Jenkins Pipeline
```
